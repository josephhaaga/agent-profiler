# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers gradually refining their personal coding-agent environment: AGENTS.md
instructions, prompts, skills, tools, and MCP definitions. Confirmed by the user
on 2026-10-28. This is not an executive metrics dashboard.

## Product Purpose

Make recorded agent behavior inspectable so users can decide what to change in
their environment and review subsequent sessions. Success is a useful next
investigation, not more graphs or stronger unsubstantiated recommendations.

## Operating Context

Local-first Bun collector and SQLite database with a React web UI. Users inspect
session history, turns, model calls, tools, prompt evidence, cache accounting,
and descriptive comparisons. OpenCode live capture and historical import coexist.

## Capabilities and Constraints

- Preserve original source identities, recorded evidence, missing-as-Unknown
  metrics, finding reconciliation, and keyboard navigation.
- No accounts, keys, cloud services, or model judges required for inspection.
- Trace evidence does not establish causation by a particular instruction, skill,
  or MCP definition. Automatic configuration attribution and editing are not
  implemented and must not be represented as available.
- All work in this iteration stays local and unpublished. Do not change the
  installed collector, dotfiles, or production data.

## Brand Commitments

The user explicitly rejects the incumbent theme and generic generated-dashboard
design language. Linear is the reference for craft and keyboard-shortcut primacy.
The user likes stackedlol/ascii-sharks as an animation reference. These references
are not permission to copy Linear assets or invent shark-related product claims.
The user subsequently clarified that animals belong in a persistent background on
every page, not a sidebar toggle or empty-state-only illustration. The seahorse
reference is https://x.com/dezinish13/status/2115140937689301263; explore other
animals within that same ASCII visual language. This correction supersedes the
initial quiet-state-only implementation.
The user selected graphite after being offered light and system-aware alternatives.
Kombai Selects is an additional user-supplied source of design inspiration.

## Evidence on Hand

Real REST records and current findings; disposable synthetic demo scenarios in
packages/cli/src/demo.ts. Synthetic data must remain labeled. No fabricated
improvement scores, config attribution, causal conclusions, or success guarantees.

## Product Principles

- Start with behavior worth investigating, then reveal measured detail.
- Keep frequent work fast from the keyboard.
- Keep evidence legible over the user-requested animal background; make motion
  pausable without removing the still scene.
- Preserve uncertainty, provenance, and the difference between error and stop.

## Accessibility & Inclusion

Keyboard-operable controls, legible text and contrast, visible focus, responsive
layouts, and reduced-motion support. Do not communicate state with color alone.
